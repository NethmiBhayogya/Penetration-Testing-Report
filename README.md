# Footprinting & Network Scanning

**Cybersecurity & Ethical Hacking Internship – Networkwalks**

This repository documents my practical activities completed during Week 02 of the Cybersecurity & Ethical Hacking Internship at Networkwalks.

The project covers two key cybersecurity activities: **Footprinting using Kali Linux tools (W2-PM1)** and **Network Scanning using Zenmap (W2-PM5)**.

## Modules Covered

### W2-PM1 – Footprinting with Multiple Kali Linux Tools

Performed information gathering and reconnaissance against `networkwalks.com` using:

- WHOIS
- WhatWeb
- nslookup
- curl
- wafw00f
- DNSRecon

### W2-PM5 – Network Scanning with Zenmap

Performed host discovery on my own local network using Zenmap (Nmap GUI).

Activities included:
- Identifying local network configuration using Windows CMD.
- Performing a Ping Scan using Nmap.
- Discovering active hosts on the local subnet.
- Identifying IP and MAC address information.
- Visualizing discovered hosts using Zenmap's Topology feature.

## Scope & Ethical Considerations

All activities were intended for educational purposes. Network scanning was performed on my own local network. Footprinting activities are documented according to the supplied practical evidence and applicable authorization scope.

No exploitation, password attacks, denial-of-service testing, or unauthorized access was performed.

**All security testing must be limited to systems owned by the tester or covered by valid written authorization.**
